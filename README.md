# tideguard

**A decision-aware model-selection harness for data-scarce surveillance forecasting**

Open, reusable harness and a baseline-first *selection rule* for deciding whether a
pre-trained time-series foundation model is worth deploying for outbreak early warning,
demonstrated on wastewater pathogen surveillance across two measurement systems and four
pathogens. The harness scores forecasters under both point-error and decision-focused
metrics with matched site-clustered uncertainty, and formalises model choice with a
Model Confidence Set (MCS; Hansen, Lunde & Nason, 2011).

## Quick start — the selection procedure

```bash
pip install -r requirements.txt
python select.py
```

`select.py` runs the rule on the deposited US panel and prints:
the point-error MCS, the decision-metric MCS, and the baseline-first recommendation.
Swap in your own `site x model` loss table and per-origin alert table
(`site, model, pred_rise, surge`) to apply it to a new programme.

## What the harness computes
| step | script |
|---|---|
| US NWSS rolling-origin benchmark (baselines + TimesFM) | `code/wbe_forecast.py` |
| Chronos-Bolt + TimesFM, decision metrics | `code/chronos_run.py` |
| Swiss 10-city panel | `code/swiss10_all.py` |
| LoRA fine-tuning and sweep | `code/finetune_timesfm.py`, `code/lora_sweep.py` |
| Independent-pathogen extension (Flu B, RSV, Flu A) | `code/pathogen_extension.py` |
| Surge early-warning + site-clustered bootstrap CIs | `code/alert_analysis.py`, `code/surge_bootstrap.py` |
| Decision-metric Model Confidence Set | `code/analysis_decision_mcs.py` |
| Signal-roughness moderator | `code/roughness_analysis.py`, `code/fig_roughness_split.py` |
| Figures | `code/fig*_*.py`, `code/fig_screening.py` |

GPU runs (foundation models, LoRA): see `code/RUN_ON_GPU.md`.

## Layout
```
select.py              decision-aware selection procedure (demo)
code/                  analysis, figure and extension scripts
data/derived/          per-configuration MAE tables, site-level losses, surge
                       per-origin outcomes, bootstrap and MCS summaries
requirements.txt  LICENSE  CITATION.cff  .zenodo.json
```

## Data
All source data are public. The US NWSS SARS-CoV-2 series download automatically from
the CDC Socrata API on first run (`code/wbe_forecast.py`). The Swiss co-located dataset
is from Baumgartner et al. (ERIC, https://doi.org/10.25678/000D6F). Only derived tables
are deposited here; raw inputs are regenerated by the scripts.
